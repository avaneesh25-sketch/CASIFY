# Cassify - Case Competition Platform

This is a responsive, feature-rich template app designed to host and track Case Competitions. Built with HTML, Tailwind CSS, and lightweight interactions.

## Features
- **Clean Landing Page**: Highlight upcoming competitions and event tracking.
- **Interactive Competitor Dashboard**: Track submission statuses, active team sizes, and remaining deadlines.
- **SaaS Layout**: Native sidebar navigation and modern cards built for great user interaction.

## Quick Start
Open `index.html` in any browser to launch the landing page, or open `dashboard.html` to explore the workspace.
